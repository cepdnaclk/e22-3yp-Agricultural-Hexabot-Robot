# Agricultural Hexabot Robot

**INSECT — IoT Networked System for Environmental and Crop Telemetry**  
Team Nova | CO3060: Computer Systems Design Project | Team 13

An agricultural hexapod robot designed to navigate uneven farm terrain, monitor environmental and soil conditions, detect weeds and pests using computer vision, and send telemetry to an online dashboard.

## Project goals
- Build a stable six-legged robot for rough farm terrain.
- Measure air temperature, soil temperature, humidity, and soil moisture.
- Use a camera and computer vision to identify weeds and pests.
- Send readings and alerts to an online dashboard.
