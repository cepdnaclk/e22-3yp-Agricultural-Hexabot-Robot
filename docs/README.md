# INSECT - IoT Networked System for Environmental and Crop Telemetry

INSECT is an intelligent agricultural hexapod robot designed to support precision agriculture by monitoring environmental conditions and crop health. Inspired by the movement of insects, the six-legged robot is designed to navigate uneven and challenging agricultural terrain. It integrates environmental sensors, soil-moisture monitoring, camera-based crop observation, and IoT connectivity to collect and transmit agricultural data to an online dashboard. The system aims to help farmers make informed decisions about crop management, identify potential pest and weed problems, and improve agricultural efficiency through robotics, sensing, and intelligent data analysis.

## Introduction

Agricultural monitoring in challenging terrain can require considerable manual effort and time. Farmers need reliable information about soil moisture, temperature, humidity, and crop health to make effective decisions. INSECT addresses these challenges through a six-legged agricultural robot that can move across uneven ground while collecting useful environmental and crop-related data. By combining robotics, sensor technology, computer vision, and IoT connectivity, the system aims to support efficient, data-driven agricultural practices.

## Solution Architecture

The system combines a hexapod mobility platform, environmental sensors, a camera-based monitoring system, and an IoT-enabled data platform. Sensor readings and captured images are processed and made available through an online dashboard, allowing users to observe agricultural conditions and review collected information.

## Hardware and Software Designs

### Hardware Design

- Six-legged robotic platform for movement across uneven agricultural terrain.
- Servo motors and a controller for coordinated leg movement using a tripod gait.
- Environmental sensors for air temperature and humidity.
- Soil-moisture sensor for monitoring soil conditions.
- Camera module for capturing crop images and supporting visual analysis.
- Embedded computing and communication components for sensing, control, and data transmission.

### Software Design

- Embedded software for robot movement and sensor data acquisition.
- Computer vision for potential weed and pest identification.
- IoT communication for transmitting collected data.
- Backend services for processing and managing agricultural information.
- Web dashboard for displaying sensor readings, crop observations, and monitoring results.

## Testing

Testing will evaluate the robot's movement, sensor accuracy, data transmission, camera functionality, and dashboard integration. The robot's ability to navigate uneven surfaces and maintain stable sensor readings will also be assessed.

## Conclusion

INSECT aims to demonstrate how robotics, environmental sensing, computer vision, and IoT technologies can be combined to support modern agriculture. The project focuses on developing a mobile hexapod platform capable of navigating challenging terrain and collecting useful agricultural data. Future improvements may include more advanced crop analysis, enhanced autonomous navigation, intelligent pest and weed detection, and expanded monitoring capabilities for precision agriculture.
